# Documentation map

Entry point for humans and agents: what lives where, and where superseded
material goes. Agent behavior rules live in the root `AGENTS.md`.

| Area | Location | Notes |
|------|----------|-------|
| Repo surface | `README.md`, `ARCHITECTURE.md`, `CONTRIBUTING.md`, `CHANGELOG.md` | Quick start, benchmarks, module map, contribution rules |
| **Codebase reference (internal)** | [`.planning/codebase/ARCHITECTURE.md`](../.planning/codebase/ARCHITECTURE.md) | Stack, structure, conventions, testing, integrations, concerns (agent-facing, not the published site) |
| **Decisions (ADRs)** | [`docs/decisions/`](decisions/README.md) | Accepted architectural decisions, `Context → Decision → Consequences`; template + process |
| Architecture & internals | `docs/pipeline-architecture.md`, `docs/medallion.md` | Hamilton DAG composition; medallion runtime |
| Topic guides | `docs/{data-loading,preprocessing,feature-engineering,models,evaluation,hpo,drift-detection,explainability}.md` | One doc per subsystem, published via mkdocs |
| Planning | `docs/plan/` | `portfolio-roadmap-20260805.md` (3-month plan), `phase2-story-depth-20260808.md`, `phase2-handoff-20260812.md`, `deferred-research.md` (consolidated future work) |
| **Handoffs (post-audit work)** | [`docs/handoffs/`](handoffs/README.md) | 2026-08-30 full-`src/` audit findings + W1–W5 workstream briefs for agent pickup (agent-facing, not in mkdocs nav) |
| Notebooks & case studies | `docs/notebooks/` | 3 hero docs (quick-start, Telco Churn demo, German Credit case study) + Phase-3 agent-demo placeholder |
| Releases | `docs/releases/` | Per-release notes |
| Findings log | `REPORT_LOG.md` (repo root) | Material findings + AI-assistance disclosure per `AGENTS.md` |
| Internal working state (not published) | `.planning/` (`OVERVIEW.md`, `STATE.md`, `STYLE.md`, `PHASE_1_2_HANDOFF.md`), `workspace/` | Agent handoff state, style rules, run artifacts |

## Archive policy

Superseded and deprecated material lives only in [`docs/archive/`](archive/README.md).
When a doc is superseded, move it there with a header note pointing at its
replacement — do not leave stale copies in live directories. (The legacy
`docs/notebooks/archive/` predates this rule and stays in place.)

## Site build

The mkdocs site (`mkdocs.yml`) is the published surface; notebook pages are
generated by `scripts/generate_notebook_docs.py` from `notebooks/*.qmd`.
Run `make docs` to render everything locally.
