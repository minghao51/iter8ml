# v0.1.0 — First public release 🚀

**iter8ml** — a high-velocity iteration framework for tabular machine learning.
Single-node, Polars-native, config-driven, orchestrated by a Hamilton DAG, with
an MCP server so an LLM agent can run experiments for you.

This first release ships the complete experiment loop —
**data → preprocess → train → evaluate → calibrate → explain → export** —
feature-complete and benchmark-validated on real datasets.

## ⚡ 30-second start

```bash
# No install — run straight from PyPI (models + Hamilton DAG via the [gbdt] extra):
uvx --from 'iter8ml[gbdt]' iter8 run --data data.csv --target label

# Or in a project:
uv add 'iter8ml[gbdt]'
iter8 run --data data.csv --target label
```

```bash
iter8 init --data data.csv           # initialize a workspace
iter8 run  --data data.csv --target y # full experiment (7 model families)
iter8 hpo  --data data.csv --target y --model catboost --trials 100
iter8 drift --reference train.parquet --new batch.parquet
iter8 leaderboard                      # ranked models + metrics
iter8 export                           # package the champion model
```

## 🧰 What's inside

- **7 model families** with hardware-aware routing — CatBoost / LightGBM / XGBoost, TabPFN v2, FT-Transformer, TabNet, + naive/linear baselines.
- **Hamilton DAG pipeline** — function-based DAG, 5 execution modes (train / drift / export / HPO / inference), inspectable lineage, lifecycle hooks.
- **HPO** — Optuna with historical warm-starting, PedYst parameter importance, pruners, search-space refinement.
- **3 drift detectors** — KS/χ², Population Stability Index, and a multivariate domain-classifier (AUC).
- **Explainability** — SHAP TreeExplainer (GBDTs) + KernelExplainer, with beeswarm & dependence plots.
- **Probability calibration** — Platt scaling & isotonic regression.
- **Experiment tracking** — zero-infra JSONL event store, plus optional W&B / MLflow.
- **Model registry & export** — thread-safe promotion + portable champion packaging (shipped predictor reproduces training-time preprocessing).
- **🤖 MCP server** — 8 atomic tools so Claude Desktop (or any MCP client) can run experiments conversationally: `iter8 mcp`.
- **Medallion runtime** — local Bronze→Silver→Gold→Platinum artifact contract with atomic products, checksum verification, and resumable runs.

---

## 🔧 Engineering highlights

- **Diagnosed & fixed a libgomp deadlock** that hung LightGBM/XGBoost on Intel hybrid-core (P+E) CPUs under WSL2/Linux — threads now conservatively capped on Linux (override via `OMP_NUM_THREADS`).
- **Polars-native throughout** (no Pandas) for Arrow-native speed.
- **Leakage audit** — a pre-train permutation test flags "too-good-to-be-true" features.
- **Safe deserialization** — a restricted unpickler allowlist on all model loads.
- Strict `mypy`, `ruff`, `pytest` (+ property / metamorphic / contract tests) in CI.

|---|---|

| `iter8ml[train]` | Adds deep models (TabPFN/FT-Transformer/TabNet), tracking, LLM/MCP, SHAP. |
| `iter8ml[full]` | `train` + docs tooling. |
| `iter8ml[docs]` | MkDocs Material site only. |

## ⚠️ Known limitations

- **Single-node only** — no distributed training (by design: fast feedback on one machine).
- **Deep / foundation models (TabPFN, FT-Transformer, TabNet) require a GPU** — the CPU benchmark above covers GBDTs only. `ModelSelector` auto-routes based on detected VRAM.
- **`[train]`/`[full]` pull `shap → llvmlite`**, which can be fragile on *fresh* Python 3.12 installs (the committed `uv.lock` resolves cleanly). Prefer `[gbdt]` for the core run path.
- APIs are still settling — expect breaking changes before 1.0.
