# Archive

Superseded and deprecated documentation lives **only** here
(per `AGENTS.md` → *Engineering conventions* and `docs/README.md`).

Rules:

1. **Move, don't delete.** When a live doc is superseded, move it into this
   directory and prepend a note:
   `> **Superseded** by <path-to-replacement> on <date>. Kept for history.`
2. Remove it from the mkdocs `nav:` live sections; link it here instead if it
   still has reference value.
3. Update inbound links in live docs to point at the replacement, not the
   archive copy.

Note: the legacy `docs/notebooks/archive/` predates this directory and stays in
place — do not duplicate it here.
